台指期量化邏輯與進出場策略

1. 多頭進場條件 (Long Setup)

價格回測 VWAP 不破 + 台灣期交所三大法人單日淨多單增加 > 2000 口 + 散戶小台多空比 < -10% (散戶做空)。

2. 空頭進場條件 (Short Setup)

價格跌破 VWAP 且反彈無力 + 期交所外資期貨未平倉淨空單 > 15000 口 + 散戶小台多空比 > +15% (散戶追多)。

3. 風險控管與停損停利 (Risk Management)

單筆交易停損固定為 45 點或進場當根 K 棒高/低點。停利採移動停利（Trailing Stop 60 點）。

EasyLanguage / MultiCharts 策略範例 

// 台灣期貨交易所 (TAIFEX) 數據介面策略範例
Inputs: 
    Length(14), 
    ROCLen(10), 
    StopLossPts(45), 
    TakeProfitPts(90);

Variables: 
    VWAP_Val(0), 
    ROC_Val(0);

// 計算 VWAP
if BarNumber = 1 then 
    VWAP_Val = Close
else 
    VWAP_Val = Sum(Close * Volume, Length) / Sum(Volume, Length);

ROC_Val = RateOfChange(Close, ROCLen);

// 進場邏輯
If MarketPosition = 0 then Begin
    If Close > VWAP_Val and ROC_Val > 0.5 then 
        Buy ("TAIFEX_Long") next bar at market; 
        
    If Close < VWAP_Val and ROC_Val < -0.5 then 
        SellShort ("TAIFEX_Short") next bar at market;
End;

// 停損與停利設置
SetStopLoss(StopLossPts * BigPointValue);
SetProfitTarget(TakeProfitPts * BigPointValue);
